# TARGET

PWA de comptage de points pour le tir à l'arc.

## Features V1
- Config : flèches/volée, volées, distance
- Saisie par clic sur la cible ou boutons
- Déficit en temps réel vers 280 et 360 pts
- Export PNG en fin de série avec tous les groupements

## Dev

```bash
npm install
npm run dev
```

## Docker

```bash
docker compose up -d
# → http://localhost:3010
```

## V2
Stats par zone, progression inter-séries dans l'image finale.
